# jem-product-scrape-kit-intel

Plugin do Claude Code da JEM Systems para scraping de catálogos de produtos (fornecedores e concorrentes) com padrões de segurança e qualidade de dados. Uma fundação reutilizável que qualquer pessoa do time usa via wizard guiado, com skills por objetivo (análise de preços, qualidade de dados, criação de produto) em cima.

**Status:** em desenvolvimento — v1 (fundação de scraping).
